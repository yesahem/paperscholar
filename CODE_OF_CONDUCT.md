# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep criticism about the
work, not the person. Harassment, personal attacks and discriminatory language are not
tolerated in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour to the maintainers privately, through a GitHub security advisory
on this repository or a direct message to a maintainer. Reports are handled confidentially.
Maintainers may remove content and restrict or ban participants who break this code.
